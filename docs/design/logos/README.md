# Filing family mark

The Agent README uses the same Filing family mark geometry and source pixels as
Filing Digest. Each self-contained SVG embeds the corresponding Digest PNG and
recolors only the two bracket regions with Agent's existing evidence accents:
`#87482e` on light backgrounds and `#edb28e` on dark backgrounds. The F, alpha,
dimensions, and spacing remain unchanged.

The shared geometry identifies the sister projects. The brown brackets connect
the mark to Agent's Ledger workspace while Digest retains its green citation
accent.
